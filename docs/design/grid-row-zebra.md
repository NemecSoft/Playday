# 网格视图行斑马纹 设计文档

> 状态：设计定稿 v1.0（2026-09-11 决策确认）
> 目标：主界面网格里，**相邻两整行**的底色交替（行 1 不铺、行 2 铺、行 3 不铺…），
> 让人一眼能把上下两行分开；颜色跟随当前主题。

## 一、已确认的决策

| 维度 | 决策 |
| --- | --- |
| 交替粒度 | **整行 vs 整行**（组内第 2、4、6… 行铺底），不是单张卡片 |
| 计数方式 | **每个分组内单独重新起算**；分组标题行不参与计数 |
| 作用范围 | 只做**网格视图**；星球视图、分组标题栏不动 |
| 层次 | 只染**行底色**；**卡片保持透明**、封面图片完全不变 |
| 强度 | **8%**（先用 3% 实测太淡、隔着卡片看不出来，调重） |
| 默认起点 | 每组**第 1 行不铺底**（让每组开头是干净底） |

## 二、实现

### 2.1 主题感知的底色变量

单一可调点是 `:root` 里的一个变量（`src/styles/global.css`）：

```css
--row-stripe: color-mix(in srgb, var(--text-primary) 8%, transparent);
```

用**主题主文字色**做叠加，所以不用给每个主题单独配色：

- 深色主题下 `--text-primary` 近白 → 得到"**发亮**"的横带；
- 浅色主题下它是深色 → 得到"**发暗**"的横带。

想按主题微调（例如深色给 10%、浅色给 6%），在该主题的 `:root[data-theme="…"]` 块里覆盖这一条即可。

### 2.2 交替靠"组内行序号"

`useVirtualGrid` 拍平分组时，给每个 `cards` 行带上组内序号 `seq`（从 0 开始，**分组标题行不参与计数**）。
`GridView` 据此加 class：

```tsx
className={`game-grid group-rows ${row.isLastInGroup ? "group-last" : ""} ${
  row.seq % 2 === 1 ? "row-stripe" : ""
}`}
```

```css
.game-grid.row-stripe {
  background: var(--row-stripe);
}
```

### 2.3 为什么"染行底"就能看见

`.grid-card` **默认是透明底**（只在 hover / 选中时才有底色），所以行底色会从这些地方透出来：

- 每张卡片四周 6px 的 padding 环；
- 卡片之间的横向缝隙（`cardGap`）；
- 行与行之间的间距（`cardRowGap`，已经包含在行高里）。

这些区域连起来读，就是"**这一行的底色和上一行不一样**"。

## 三、影响面

| 文件 | 改动 |
| --- | --- |
| `src/styles/global.css` | `:root` 加 `--row-stripe`；新增 `.game-grid.row-stripe` 规则 |
| `src/hooks/useVirtualGrid.ts` | `cards` 行新增 `seq`（组内序号） |
| `src/components/views/GridView.tsx` | 按 `seq % 2` 加 `row-stripe` class |

## 四、非目标

1. 不给卡片加底色、不改封面（用户明确是"整行"而不是"封面的底色"）。
2. 不加"斑马纹开关"（YAGNI；想关掉就把 `--row-stripe` 设成 `transparent`）。
3. 不做"色带比卡片更高"那种加高的横带（会改变行间距的视觉密度）。
4. 列表 / 详情 / 星球视图不做斑马纹。

## 五、已知局限

`.grid-card` 是透明底、封面占据卡片绝大部分面积，所以斑马纹的可见面积就是卡片四周那一圈。
如果嫌不够明显，可选的下一步是"让隔行的卡片本身也铺上底色"（卡片面与行底连成一条完整色带），
但那会改变卡片观感，需要另行确认。

## 六、验证

1. 网格视图（不分组或分组都行）里，相邻两整行的底色肉眼可分；每组的第 1 行是干净底。
2. 换几个主题（深色 / 浅色各试一个）→ 斑马纹自动跟着变亮或变暗，不需要单独调。
3. 折叠 / 展开某个分组后，剩下的行重新交替（不会出现两行同色相邻）。
4. `tsc` 报错数仍为 43（基线）；`npm run build` 通过。
