## Playday 游戏库内容批量补全（game-content.json → game-content-new.json）

- 原始文件 `game-content.json`：1283 条游戏，`gameid / name / intro / region / tags / gamelevel` 六字段结构；补全前 1229 条 region 为空、1054 条 tags 为空，且部分 intro 张冠李戴（如"巫师2"写成《亡灵魔法模拟器》、"行尸走肉：全季版"写成解谜游戏）。
- 目标：为全部 1283 条重写 intro / region / tags，输出**新文件** `game-content-new.json`，`gameid / name / gamelevel` 三个字段按原样复制、绝不改动，不增删条目。
- 做法：
  1. 用 PowerShell 把清单按每 100 条拆成 `_batch_01..13.txt`（格式 `序号|游戏名|旧简介`）。
  2. 写统一规范 `_SPEC.md`（简介写法/地区口径/标签规则/命名后缀规则/输出格式），保证风格一致。
  3. 并行派 13 个 subagent，各处理一个批次，**逐条联网核实开发商所在国**，各自产出 `_patch_01..13.json`。
  4. `_validate.py` 校验（条目数、name 逐字一致、四键结构、intro 长度与违规开头、tags 数量与游戏名污染）→ `_build.py` 合并生成最终文件 → `_final.py` 新旧比对。
- 结果：1283/1283 全覆盖，校验零问题；新旧文件 gameid/name/gamelevel 不一致数 0；三字段无空值。地区共 53 种（美国 248、日本 167、中国大陆 121、英国 100、加拿大 88…，`未知` 仅 9 条）。
- 关键口径（用户确认）：region = **开发商所在地**（非发行商、非发售市场）；中国大陆/中国台湾/中国香港单独标注；跨国大厂归"欧美"。
- 命名规则：带 `-网吧联机版 / -联机版 / -MOD版 / 私服联机版 / 全DLC版` 后缀的条目，按**基础游戏**填写。
