# 游戏内容补齐规范（必须严格遵守）

你要为一个中文游戏库的每一款游戏，生成 `intro`（简介）、`region`（发行地区）、`tags`（标签）三个字段。

## 一、原始数据
批次文件 `_batch_XX.txt`，每行格式：`序号|游戏名|旧简介`。
- 旧简介**仅供理解游戏用**，质量参差、有的还张冠李戴，**不要在它基础上直接改**，要按你自己的理解重写。
- 遇到明显错的旧简介（例如"巫师2"的简介写的却是别的游戏），以**游戏名对应的真实作品**为准。

## 二、intro（简介）写法 —— 最重要
1. **长度**：一段话，约 60～120 个汉字。
2. **开头**：必须直接进入动作，用「扮演……」「操控……」「你将……」「带领……」「作为……」这类句式开头。
   - **严禁**以"这是一款""本作是""该作是"开头。
   - **严禁**写"由 XX 工作室开发""XX 出品的"这类百科/媒体腔。
3. **必须讲清楚四件事**：这是什么游戏（玩法/类型）、你扮演谁或操控什么、你要做什么、故事梗概。
4. **目标读者**：完全没听说过这款游戏的人，看完这句话就知道这游戏是干嘛的。
5. **文风**：简洁、口语化、有画面感。像在跟朋友安利。不要用排比句堆砌，不要卖弄辞藻。
6. 尽量**不要在简介里出现游戏名本身**。
7. 标点用中文全角；游戏内专有名词（人名、地名）首次出现可保留原名或通用译名。

**好例子：**
- 扮演美国战争英雄 B.J. 布拉柯威兹，在纳粹赢得二战、统治全球的 1960 年，从精神病院醒来后一路杀穿欧洲，从纳粹手里夺回超级武器，发动一场看似不可能的反击。
- 操控鸣人、佐助等 110 名忍者，从初代火影对决打到第四次忍界大战终结，用华丽的奥义和觉醒技在 3D 战场上格斗。
- 用一个按键控制两颗相互缠绕的火焰与冰川之星，跟着音乐节拍在蜿蜒轨道上前进，抢拍或慢拍都得从头再来。

**坏例子（禁止）：**
- 《塞尔达传说：王国之泪》是《荒野之息》的续集……（百科腔、出现游戏名、没讲扮演谁）
- 一款在废弃的月球上捡垃圾卖钱的合作恐怖游戏。（"一款……"开头，没人称动作）

## 三、region（发行地区）写法
只填**一个**地区，取**开发商（工作室）所在地**，不是发行商、不是发售市场。
- 国家级工作室 → 填国家名，用常见中文译名：日本、美国、英国、法国、德国、波兰、瑞典、芬兰、挪威、丹麦、荷兰、比利时、奥地利、捷克、乌克兰、俄罗斯、西班牙、葡萄牙、意大利、希腊、爱尔兰、冰岛、匈牙利、罗马尼亚、土耳其、以色列、加拿大、墨西哥、巴西、阿根廷、韩国、澳大利亚、新西兰、印度、印度尼西亚、越南、菲律宾、泰国、新加坡、马来西亚、阿联酋、伊朗……
- 中国大陆团队 → `中国大陆`
- 中国台湾团队 → `中国台湾`
- 中国香港团队 → `中国香港`
- 工作室横跨多国、或难以归到单一国家的欧美大厂 → `欧美`
- 实在没查到，用 `未知`（尽量少用）

**判断依据必须联网核实**：对没把握的游戏，用联网搜索「游戏名 + 开发商 / developer」确认，不要凭印象瞎填。知名大厂作品（如任天堂=日本、CDPR=波兰、FromSoftware=日本、Rockstar=欧美）可直接填。

## 四、tags（标签）写法
- **至少 5 个**，建议 5～6 个。格式严格为：`#标签1 #标签2 #标签3 #标签4 #标签5`（井号开头、空格分隔，无逗号）。
- 每个标签是 **2～6 个汉字**的中文短词，不要带英文、不要带空格。
- **绝不能包含游戏名本身**，也不要包含作品系列名。
- 覆盖维度建议：玩法类型（#第一人称射击 #动作角色扮演）、玩法特征（#肉鸽 #塔防 #潜行）、题材（#科幻 #北欧神话 #抗战题材）、视角/画面（#像素风 #横版 #3D）、模式（#单人战役 #多人联机 #合作）、气质（#恐怖 #治愈 #硬核）。
- 不要用"#游戏""#好玩"这类无信息量的词。

**示例：** `#第一人称射击 #架空历史 #纳粹 #单人战役 #暴力`

## 五、名字规则
- 带 `-网吧联机版`、`-联机版`、`-私服联机版`、`-MOD版`、`MOD版`、`-全DLC版` 等后缀的，指的是**基础游戏**：简介按基础游戏写，region 按基础游戏的开发商填。
- 带 `重制版`、`终极版`、`威力加强版`、`DX`、`第一章`、`2`、`3` 等作品自身版本/序号后缀的，按该作品本身填写。

## 六、输出格式（严格执行）
把结果写入指定的 `_patch_XX.json` 文件（UTF-8 无 BOM），内容是一个 JSON 数组，每个元素恰好四个键：

```json
[
  {
    "name": "傲气雄鹰：重装上阵",
    "intro": "扮演一名飞行员，驾驶战机在竖版天幕里左右闪避、吃道具升级，把一波波敌机和 Boss 打成满天爆炸的街机射击。",
    "region": "波兰",
    "tags": "#竖版射击 #街机 #弹幕 #升级解锁 #单人"
  }
]
```

- `name` 字段必须与批次文件里的游戏名**逐字完全一致**（含所有后缀），否则会被丢弃。
- 批次里**每一条都必须输出**，不允许跳过、不允许省略、不允许写"……"。
- 不要输出 JSON 之外的任何解释文字到文件里。
